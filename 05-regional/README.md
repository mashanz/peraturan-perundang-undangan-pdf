# 05-REGIONAL - Regional Government Regulations
## 🏘️ Provincial and Local Government Regulations

This directory contains regulations issued by regional governments (provinces, regencies, and cities).

### Directory Structure
- **by-province/** - Provincial regulations (PERDA Provinsi)
- **by-regency/** - Regency and city regulations (PERDA Kabupaten/Kota)

### Document Types
- **PERDA Provinsi**: Provincial-level regional regulations
- **PERDA Kabupaten/Kota**: Regency and city-level regulations
- **PERGUB**: Governor regulations
- **PERBUP/PERWALI**: Regent/Mayor regulations

### Hierarchy Level: **LEVEL 5** ⭐
