# 03-GOVERNMENT-REGULATIONS - Executive Regulations
## 🏢 Presidential and Government Implementing Regulations  

This directory contains regulations issued by the President and Government to implement higher-level laws.

### Directory Structure
- **pp/** - Government Regulations (Peraturan Pemerintah)
- **perpres/** - Presidential Regulations (Peraturan Presiden)
- **inpres/** - Presidential Instructions (Instruksi Presiden)

### Document Types
- **PP**: Government regulations that implement laws (require DPR consultation)
- **PERPRES**: Presidential regulations for administrative and organizational matters
- **INPRES**: Presidential instructions for policy implementation

### Hierarchy Level: **LEVEL 3** ⭐⭐⭐
These regulations implement higher laws and bind all government institutions.

### Filename Convention
- Government Regulations: `pp-[number]-[year].pdf`
- Presidential Regulations: `perpres-[number]-[year].pdf`
- Presidential Instructions: `inpres-[number]-[year].pdf`
