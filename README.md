# 📄 Indonesian Legal Regulations - PDF Archive

**PDF Repository for Indonesian Legal System**

This repository contains the original PDF files of Indonesian legal regulations, separated from the main markdown repository for efficient organization.

## 🔗 Related Repository
**Main Repository (Markdown):** https://github.com/mashanz/peraturan-perundang-undangan

## 📁 Contents
- Original PDF files of Indonesian legal regulations
- Ministry regulations (Permen) in PDF format
- Government regulations (PP) in PDF format  
- Law documents (UU) in PDF format
- All hierarchy levels preserved in original format

## 📋 Organization
PDFs are organized by ministry and regulation type, maintaining the original file naming conventions from Indonesian government sources.

---
**Purpose:** Archive and preserve original PDF documents while keeping the main repository clean for markdown conversions.
