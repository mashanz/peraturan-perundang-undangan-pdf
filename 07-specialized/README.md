# 07-SPECIALIZED - Specialized Institution Regulations
## 🏛️ Independent Institutions and Special Authority Regulations

This directory contains regulations from specialized institutions and independent bodies.

### Directory Structure
- **bpk/** - Supreme Audit Agency (Badan Pemeriksa Keuangan)
- **kpu/** - General Election Commission (Komisi Pemilihan Umum)
- **other-institutions/** - Other specialized bodies and miscellaneous documents

### Institution Types
- **BPK**: Financial audit and accountability regulations
- **KPU**: Electoral and democratic process regulations
- **Independent Commissions**: Anti-corruption, human rights, etc.
- **Technical Agencies**: Standards, certification, specialized functions
- **Miscellaneous**: Documents that don't fit other categories
